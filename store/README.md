- Violence, sexe, langage grossier, drogues, jeux d'argent : non
- Contenu généré par les utilisateurs : oui, mais partagé uniquement en privé,
  au sein d'un groupe invité par code (pas de contenu public, pas de chat ouvert)
- Partage de la position : uniquement avec les membres du voyage, à l'initiative de l'utilisateur
- Publicités : non
- Achats intégrés : non
- Classification attendue : Tous publics / PEGI 3

## Formulaire Sécurité des données (Data safety)
Données collectées : uniquement si la synchronisation est activée (facultative).
- Contenu utilisateur (récits de voyage, réservations, dépenses), photos,
  noms/initiales des voyageurs : collectés, chiffrés de bout en bout, stockés sur Cloudflare
  - Finalité : fonctionnalités de l'appli
  - Facultatif : oui (sans synchro, tout reste sur l'appareil)
- Position approximative : seulement quand l'utilisateur appuie sur « Je suis ici »
  ou active le suivi du trajet ; stockée dans son carnet, chiffrée
  - Finalité : fonctionnalités de l'appli ; facultatif : oui
- Identifiants appareil : compteur d'installations anonyme (identifiant aléatoire + type d'appareil)
  - Finalité : statistiques (analytics) ; non lié à l'identité
- Partage avec des tiers : aucun (pas de publicité, pas de revente)
- Chiffrement en transit : oui (HTTPS)
- Suppression des données : oui
  - bouton dans l'appli
  - https://<your-domain>/suppression-donnees.html
- Aucun compte requis
