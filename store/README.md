## Questionnaire de classification du contenu (IARC)
- Violence, sexe, langage grossier, drogues, jeux d'argent : non
- Contenu généré par les utilisateurs : OUI. Partagé avec les compagnons invités par code, et — si l'auteur
  publie un voyage — avec ses abonnés (toute personne qui a reçu son lien). Les abonnés peuvent commenter et aimer.
  L'appli propose : signaler (🚩), bloquer une personne, supprimer un commentaire, changer le lien.
- Partage de la position : oui, à l'initiative de l'utilisateur (compagnons ; abonnés seulement s'il l'active)
- Publicités : non (les liens partenaires signalés « partenaire » ne sont pas des annonces affichées)
- Achats intégrés : non tant que les formules Plus et Max ne sont pas ouvertes ; à passer à OUI à leur ouverture
- Classification attendue : Tous publics / PEGI 3 (avec la mention « interactions entre utilisateurs »)

## Formulaire Sécurité des données (Data safety) — MIS À JOUR le 10/11/2026
⚠️ L'ancienne version disait « aucun compte requis » : ce n'est plus vrai depuis le compte obligatoire pour le carnet en ligne.
À déclarer dans la Play Console :
- L'appli collecte-t-elle des données ? OUI. Chiffrées en transit : OUI. Suppression possible : OUI.
- Création de compte : OUI (adresse e-mail vérifiée par un code, sans mot de passe)
  - URL de suppression du compte : https://vezoria.pages.dev/suppression-donnees.html
- Informations personnelles → Adresse e-mail : collectée, non partagée ; finalité : gestion du compte ; obligatoire pour le carnet en ligne
- Informations personnelles → Nom (prénom du profil) : collecté (chiffré de bout en bout), non partagé ; fonctionnalités de l'appli
- Photos et vidéos → Photos : collectées (chiffrées de bout en bout), non partagées ; fonctionnalités ; facultatif
- Fichiers et documents (billets, PDF joints) : collectés (chiffrés), non partagés ; fonctionnalités ; facultatif
- Position → approximative ET précise : collectées seulement si l'utilisateur touche « Je suis ici » ou active le suivi
  (appli ouverte uniquement, jamais en arrière-plan) ; chiffrées ; non partagées avec des tiers ; fonctionnalités ; facultatif
- Messages → autres messages dans l'appli (commentaires) : collectés (chiffrés) ; fonctionnalités ; facultatif
- Activité dans l'appli → autres contenus générés par l'utilisateur (voyages, dépenses, notes) : collectés (chiffrés) ; fonctionnalités
- Informations financières : NON (les dépenses saisies sont du contenu utilisateur ; aucun moyen de paiement n'est collecté par l'appli)
- Infos et performances de l'appli → journaux de plantage / diagnostics : collectés (rapports d'erreur anonymes) ; analyse
- Appareil ou autres identifiants : identifiant aléatoire du compteur d'installations et des appareils validés ; analyse et gestion du compte
- Partage avec des tiers : aucun (l'hébergeur Cloudflare est un sous-traitant, pas un tiers au sens de Google)
- « Chiffré de bout en bout » ne dispense pas de déclarer : Google demande de déclarer ce qui quitte l'appareil.
