## App name (≤30)
Vezoria – みんなの旅手帳

## Short description (≤80)
旅を計画し、楽しみ、残す。無料・広告なし・オフライン対応・暗号化。

## Full description (≤4000)
Vezoria は旅のすべてをひとつにまとめます：予定、予約、予算、思い出。無料で広告なし、アカウント不要で、電波がなくても使えます。

準備
• 日ごとの予定：日の追加・削除、日程の変更
• 予約：移動、ホテル、観光など
• PDF や確認メールから予約をインポート：スマホ上で読み取り、種類を自動判別。同じ日付に重複があれば、残すか置き換えるかを選べます
• 「見どころ」：各立ち寄り先の周辺スポットと、自分で追加した場所
• 予算：誰が何を払ったか、支払い計画
• 行きたい場所、アイデア、チェックリスト

旅行中
• 今日のシートをひと目で
• 位置情報付きのステップ
• レシート写真付きの支出
• アプリを開いているあいだのルート記録
• 写真付きの思い出

旅行のあと
• 3D 地球儀であなたの旅を
• 訪れた国と統計
• ZIP バックアップ
• PDF のフォトアルバム

まとめ
• 誰が誰にいくら、返済
• 1人ごとの残高と領収書

一緒に旅する
コードひとつでパートナーや友だちと旅行を共有。それぞれに色があり、変更には名前が付くので、誰が何を変えたかいつでもわかります。

あなたのデータはあなたのもの
• アカウントなし、広告なし
• すべてオフラインで動作
• 同期は任意、エンドツーエンドで暗号化
• データのエクスポート（ZIP）から旅行をインポート

シンプルにもフルにも
使わないタブや枠を隠して、アプリを軽く保てます。14言語に対応。

よい旅を！
