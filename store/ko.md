## App name (≤30)
Vezoria – 함께하는 여행 수첩

## Short description (≤80)
여행을 준비하고, 즐기고, 간직하세요. 무료, 광고 없음, 오프라인, 암호화.

## Full description (≤4000)
Vezoria는 여행의 모든 것을 한곳에 모아 줘요: 일정, 예약, 예산, 추억. 무료이고 광고가 없으며 계정도 필요 없고, 인터넷 없이도 작동해요.

준비
• 날짜별 일정: 날짜 추가·삭제, 일정 변경
• 예약: 교통, 호텔, 관광 등
• PDF나 확인 메일로 예약 가져오기: 휴대폰에서 바로 읽고 종류를 알아내며, 같은 날짜에 중복이 있으면 유지할지 바꿀지 직접 골라요
• “볼거리”: 경유지마다 주변 장소와 내가 추가한 장소
• 예산: 누가 무엇을 냈는지, 결제 일정
• 위시, 아이디어, 체크리스트

여행 중
• 한눈에 보는 오늘의 시트
• 위치가 담긴 걸음
• 영수증 사진과 함께 지출 기록
• 앱이 열려 있는 동안 경로 기록
• 사진이 있는 추억

여행 후
• 3D 지구본 위의 내 여행
• 가 본 나라와 통계
• ZIP 백업
• PDF 사진 앨범

결산
• 누가 누구에게 얼마, 상환
• 사람별 잔액과 영수증

함께 여행하기
코드 하나로 연인이나 친구와 여행을 공유하세요. 각자 색상이 있고 모든 수정에 이름이 남아서 누가 무엇을 바꿨는지 항상 알 수 있어요.

내 데이터는 내 것
• 계정 없음, 광고 없음
• 모든 기능이 오프라인에서 작동
• 선택형 동기화, 종단간 암호화
• 데이터 내보내기 파일(ZIP)에서 여행 가져오기

간단하게 또는 자세하게
쓰지 않는 탭과 영역을 숨겨 앱을 가볍게 유지하세요. 14개 언어 지원.

즐거운 여행 되세요!
