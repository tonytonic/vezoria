## App name (≤30)
Vezoria – 结伴旅行手账

## Short description (≤80)
规划、体验并珍藏你的旅行。免费、无广告、可离线使用、全程加密。

## Full description (≤4000)
Vezoria 把整个旅行集中在一个地方：行程、预订、预算和回忆。它免费、没有广告、无需注册账号，没有网络也能使用。

规划
• 逐日行程：添加或删除天数，修改日期
• 预订：交通、酒店、参观等
• 从 PDF 或确认邮件导入预订：在手机上读取，自动识别类型；如果同一日期已有重复条目，由你选择保留或替换
• 「看点」：每个站点周边的地点，以及你自己添加的地点
• 预算：谁付了什么，付款计划
• 心愿、点子和清单

旅途中
• 当日速览，一目了然
• 带定位的足迹
• 拍下票据记录开销
• 应用打开时记录路线
• 带照片的回忆

旅行之后
• 在 3D 地球上查看你的旅行
• 去过的国家和统计数据
• ZIP 备份
• PDF 相册

总结
• 谁欠谁多少、还款
• 每人余额和凭证

一起旅行
用一个代码与伴侣或朋友分享旅行。每个人都有自己的颜色，每次修改都会署名，谁改了什么一清二楚。

你的数据属于你
• 无需账号，没有广告
• 一切都能离线使用
• 可选同步，端到端加密
• 从数据导出文件（ZIP）导入你的旅行

简洁或完整，由你决定
隐藏不用的标签页和板块，让应用保持轻巧。支持 14 种语言。

旅途愉快！
